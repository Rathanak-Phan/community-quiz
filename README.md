# Community-Based Quiz Management System

A full-stack web application that allows users to create, manage, and participate in quizzes within structured communities.  
The system supports role-based access control, hybrid grading (automatic and manual), and leaderboard ranking.

This project was developed as a **Project** for the **Bachelor of Engineering in Information Technology Engineering** at the **Royal University of Phnom Penh (RUPP)**.

---

## Project Overview

The Community-Based Quiz Management System is designed to improve collaborative learning by allowing users to create communities where quizzes can be shared, attempted, and evaluated.

Unlike traditional quiz platforms, this system integrates:

- Role-based authorization
- Community management (public/private)
- Multiple question types
- Hybrid grading system
- Leaderboard ranking
- Favorite system
- Production-ready architecture

The system follows a **three-tier architecture** consisting of a frontend, backend API, and relational database.
